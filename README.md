# Swiggy Sales Analysis Dashboard

An interactive, data-driven Excel dashboard designed to analyze Swiggy's sales performance, customer preferences, and geographic trends. This project transforms raw operational data into actionable commercial insights.

## 📊 Key Metrics & Insights
* **Total Revenue:** ₹53.01 Million
* **Total Orders Placed:** 197.4K
* **Average Customer Rating:** 4.34 (across 5.59M rating counts)
* **Average Order Value (AOV):** ₹268.51

## 📈 Features & Visualizations
* **Sales Trends:** Breaks down revenue fluctuations across Monthly, Weekly, and Daily intervals to track high-demand periods.
* **Geographic Breakdown:** An interactive map visualizes "Sales by State," complemented by a specific table showcasing quarterly performance metrics (Sales, Ratings, Orders).
* **Top Performers:** A horizontal bar chart isolating the "Top 5 Cities by Sales" (Led by Bengaluru at ₹5.46M).
* **Dietary Preferences:** A donut chart illustrating customer choices between Non-Veg (63%) and Veg (37%) options.
* **Interactive Slicers:** Dynamic filtering capabilities by Month, Food Category, and Specific Restaurant Names for granular data exploration.
